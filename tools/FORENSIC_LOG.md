# Tidelyne forensic audit log

Purpose: a permanent record of every finding raised by the forensic audit loop (one lens per auditor, one fixer per lens, one merger per round), with the fix that shipped and its status. Every finding is logged, including the ones that were deferred or could not be reproduced, so later rounds never re-discover the same issue without seeing what was decided. Findings JSON and the auditors' evidence live in the session scratchpad; the code is on main.

Column legend: **ID** — lens-scoped finding id (R<round>-<LENS>-<n>) · **Page** — hash route(s) or file the finding applies to · **Severity** — the auditor's rating (high / medium / low) · **Finding** — the auditor's one-line summary · **Fix applied** — what the fixer changed (and how the merger reconciled overlapping fixes) · **Status** — fixed / partial / deferred / not-reproduced.
